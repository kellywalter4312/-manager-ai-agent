# USER (example)

Committed as a structural example. Copy this to `USER.md` and replace the
contents with your own - `USER.md` is gitignored so your real skills, seniority
and rate expectations never reach the repository.

Tiers decide what the agent may claim on your behalf:

  Strong   - demonstrated; counted fully in a match
  Working  - usable with support; counted at half weight
  Learning - in progress; NEVER counted as a match, only mentioned as context

Every section is optional except Skills. Missing information is reported as
unknown rather than guessed.

## Projects

Format: `Name - description [skills: a, b, c]`

The skills list is what the project genuinely demonstrates - not everything it
touched. It is used to show which of your work supports a given match.

- Example Orchestrator - small multi-agent project [skills: python, testing]
- Example Website - static site [skills: javascript]
